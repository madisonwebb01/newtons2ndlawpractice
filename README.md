# Newton's 2nd Law Practicer

Whole-class F = ma whiteboard practice for Unit 3: Newton's Laws. 43 problems in 5 levels: F = ma basics, Ratios, F_net first, Weight (F_g = mg, g = 9.8 m/s²), and F = ma + kinematics.

## How to use
- Project it. Students solve on whiteboards.
- → (or a clicker) reveals the final answer; press again for the next question. ← goes back.
- "Click to show the work" (or ↓ / Space) shows the givens, worked steps and a "Watch for" note. ↑ hides it.
- Jump by level tab or question number. "Skip this one" removes a question from Next/Back.
- "Equations" lists F_net = ma, F_g = mg, the kinematics equations, units and solving steps.

## Hosting on GitHub Pages
1. Create a public repo (suggested name: `fma-practicer`).

3. Settings → Pages → Deploy from branch → `main` / root → Save.
